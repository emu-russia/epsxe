# testing

Юнит-тесты отдельных модулей эмулятора в CppUnitTest Framework.

Проект: `UnitTest/UnitTest.slnx` (проект `UnitTest.vcxproj`).

## Модули

- `UnitTest.cpp` — каркас тестового проекта.
- `zip_test.cpp` — тесты модуля работы с ZIP-архивами (`src/zip.c`):
  загрузка списка записей (`zip_load_file`), извлечение записей
  (`zip_extract_file`) со stored и deflated (сжатие DEFLATE) данными,
  поиск без учёта регистра и по конечному компоненту пути, а также
  обработка ошибочных ситуаций (файл не найден, не ZIP, пустой архив,
  запись не найдена).

Тестовые архивы создаются на лету (stored и raw-deflate записи через
zlib) во временной папке и удаляются после каждого теста.
