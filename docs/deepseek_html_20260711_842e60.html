⏺ MEMORY MAP RAM · BIOS · PIO · SCRATCH
Offset Macro Address Description
— PSX_RAM_BASE 0x00000000 Main RAM base (2 MB default, up to 8 MB on dev units)
— PSX_RAM_SIZE 2 MB Size of main RAM (2 * 1024 * 1024)
— PSX_RAM_CACHED_BASE 0x80000000 Cached access mirror of RAM
— PSX_RAM_UNCACHED_BASE 0xA0000000 Uncached access mirror of RAM
— PSX_BIOS_BASE 0x1FC00000 BIOS ROM base (512 KB)
— PSX_BIOS_UNCACHED_BASE 0xBFC00000 Uncached BIOS mirror
— PSX_BIOS_SIZE 0x80000 BIOS size (512 KB)
— PSX_PIO_BASE 0x1F000000 Parallel I/O region for expansion devices
— PSX_SCRATCH_BASE 0x1F800000 Scratchpad RAM (data cache) – 1 KB
— PSX_SCRATCH_SIZE 0x400 Scratchpad size (1 KB)
— PSX_HW_BASE 0x1F800000 Base for most I/O registers (hardware control)

✦ Пояснения к таблицам

Все адреса указаны как физические (используются в PlayStation).
Базовый адрес ввода‑вывода PSX_HW_BASE = 0x1F800000. Большинство регистров сдвинуты относительно него.
Розовым выделены ключевые регистры (data, main, init, DMA‑каналы, GPU, MDEC).
Регистры Unknown / Delay часто используются для создания задержек в коде.
SPU содержит 24 звуковых канала, управление через пары регистров (первая половина – каналы 0‑15, вторая – 16‑23).
DMA каналы: MDEC (2 канала), GPU, CD‑ROM, SPU, а также два дополнительных (DMA5, DMA6).
Root Counters — это 4 таймера (T0..T3) с режимами и целевыми значениями.
PIO используется для устройств расширения, содержит адреса функций main/init и лицензионные строки.
