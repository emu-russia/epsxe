⏣ OVERVIEW

01 / 08

SPU — 24 hardware voices, each with programmable ADSR envelope, independent left/right volume, and support for ADPCM compressed samples.

I/O Port Range1F801C00h – 1F801FFFh
Memory512 KByte RAM
Sample Rate44.1 kHz (mixer)
Data Bus16-bit
DMADMA4 (read/write)
InterruptIRQ9

NOTE 32-bit writes are unstable — use 16-bit halfword accesses.
NOTE 8-bit writes to odd addresses are ignored.

⏣ VOICES

03 / 08

Capabilities

24 hardware voices, each with:
· ADPCM sample playback
· Noise generator (shared freq)
· Frequency modulation (PMON)
· Programmable ADSR envelope
· Left/Right volume
· Reverb send (EON)

Voice Flags

KON 1F801D88h — Key On
KOFF 1F801D8Ch — Key Off
ENDX 1F801D9Ch — Loop End status
PMON 1F801D90h — Pitch Mod
NON 1F801D94h — Noise mode
EON 1F801D98h — Reverb send

NOTE Voice 1 & 3 have capture buffers.
NOTE No square-wave generation without sample data.

⏣ ADPCM SAMPLES

04 / 08

SPU-ADPCM — compressed samples in 16-byte blocks. Uncompressed PCM is not supported natively.

00h Shift/Filter 01h Flag Bits 02h–0Fh Compressed Data (28 nibbles)

Flag Bits (byte 01h):

Bit 0 — Loop End (set ENDX, jump) Bit 1 — Loop Repeat (force release) Bit 2 — Loop Start (copy addr to repeat) Bits 3–7 — unknown (usually 0)

LOOP One-shot samples must end with a silent dummy block.
XA XA-ADPCM is decoded by CDROM controller, not by SPU.

⏣ PITCH & FREQUENCY

05 / 08

Sample Rate

VxPitch 1F801C04h+N*10h
1000h = 44.1 kHz
4000h = max (176.4 kHz)
0 = stop

PMON Pitch modulation uses amplitude from voice x-1.

Interpolation

4-point Gaussian interpolation.
256-entry table (0..1FFh).
Bit4–11 of pitch counter = index.

Table is slightly bugged: sums to 7F7Fh..7F81h (not 8000h).

FORMULA Step = VxPitch · (VxOUT + 8000h) / 8000h  →  clipped to 4000h

⏣ ADSR ENVELOPE

06 / 08

Attack · Decay · Sustain · Release — programmable per voice.

ATTACK DECAY SUSTAIN RELEASE
1F801C08h 1F801C08h 1F801C0Ah 1F801C0Ah
Mode: Linear / Exponential Direction: Increase / Decrease Shift: 0..1Fh (speed) Step: +7..+4 or −8..−5

KON starts Attack · KOFF switches to Release.
CURRENT 1F801C0Ch+N*10h — read/write ADSR volume.

⏣ REVERB SYSTEM

07 / 08

Reverb — 22050 Hz processing with comb filters, all-pass filters, and reflection stages.

INPUT → SAME/DIFF → COMB → APF1 → APF2 → OUTPUT
vLOUT / vROUT 1F801D84h mBASE 1F801DA2h (start addr) dAPF1 / dAPF2 offsets vCOMB1–4 comb volumes vAPF1 / vAPF2 all-pass volumes vLIN / vRIN input volumes

EON 1F801D98h — voice reverb send
SPUCNT.bit7 Reverb Master Enable
BUG vIIR = −8000h inverts output.
